# Atship Services — design preview (V4)

Design-review prototype for Atship Services Ltd. Not an official production website. The homepage includes the CSL Tacoma photograph; confirm licensing/permission before public use.

## Publish with GitHub Pages

1. Create a **public** GitHub repository (e.g. `atship-website`).
2. Upload the **contents** of this folder into the repository root, ensuring `index.html` is at the top level (not nested in another directory).
3. Go to **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
4. Select `main`, folder `/ (root)`, then **Save**.
5. The test link will normally be `https://YOUR-USERNAME.github.io/atship-website/`.

Updates pushed to main are automatically published. No DNS configuration is needed for the preview.

## Important

- GitHub Pages and the repo are **public** on GitHub Free; do not upload passwords, client information, or internal documents.
- GitHub Pages is intended primarily for project showcases, **not as commercial business hosting**; migrate the approved corporate website to a proper host.
- `noindex`/`robots.txt` discourage search indexing, **not access**. Anyone with the URL can access the site.
- The contact form opens the visitor's email application; it does not submit data to a server.
- Check the use rights for the CSL Tacoma image and all third-party graphics before publicly publishing.
- The final company website must be approved by Jim; do not point atshipservices.com to this demo.
